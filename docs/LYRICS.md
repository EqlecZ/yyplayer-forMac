# 歌词页主题与排版

点击播放器左下封面进入歌词页；点击大封面返回进入前的页面。封面展开 / 收回采用同一张图片的连续移动与缩放，带轻微回弹；「减少动态效果」关闭封面和颜色转场。

默认从当前歌曲的真实封面提取主题色。歌词页采用与 Android 版相同结构的背景：带色底色、左侧大范围径向柔光、右侧辅色光和底部渐变；覆盖整个窗口。播放 / 暂停按钮、进度与音量条、其他播放图标、倍速下拉、歌词样式和播放选项都跟随封面色。

进入 / 返回歌词页时，背景和控件颜色随 420ms 页面转场连续混合；返回后恢复浏览页的应用主题。歌词页换歌后，实际封面颜色以 950ms 平滑更新。背景为静态渐变，不持续呼吸。

内嵌封面、本地同名 / 目录图片和已获取的联网封面共用取色路径。无封面或全透明图片回退到应用主题色，灰度图片保留中性色；下一首开始时撤下上一张封面的颜色。四种矢量背景叠在同一柔光底色上，可继续选择本地背景图。关闭「从专辑封面提取主题色」则整页使用应用主题色。

歌词页右上角点击「歌词样式」实时调整，也可在「设置 → 歌词」查看完整预览。参数自动保存，重启后恢复；「恢复歌词页默认设置」只重置下表和两个歌词页开关。

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| 歌词行间距 | 24 px | 0–80 px |
| 普通行字号 | 20 px | 12–48 px |
| 普通行不透明度 | 55% | 0–100% |
| 普通行字重 | 400 | 100–900，步长 100 |
| 当前行字号 | 28 px | 12–64 px |
| 当前行字重 | 700 | 100–900，步长 100 |
| 副语言字重 | 400 | 100–900，步长 100 |
| 两种语言间距 | 8 px | 0–40 px |

行间距作用于相邻歌词块，双语间距只作用于同一歌词块的主 / 副语言。副语言字号为该行主语言的 72%，字重独立；高亮整组语言，点击任一语言跳转到同一原始时间戳。换行按实际字体与可用宽度测量，当前行居中跟随；过长的整组歌词可以手动滚动阅读。字体族仍在「设置 → 字体」中独立选择。

例如 `Listen to the evening / 听见晚风` 显示为原文在上、译文在下。分隔符为带空格的 ` / `；`AC/DC`、日期和 URL 中普通斜线保留原样。关闭「双语歌词上下行显示」可恢复原始一行文字。分行不改源文件、时间戳或歌词偏移，纯文本歌词也可按双语排版。

Windows 排版验收见[歌词页验收](validation/lyrics-page.md)，完整主题 / Android 背景的后续截图与限制见[主题验收](validation/lyrics-theme.md)。
