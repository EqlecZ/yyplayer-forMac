# ADR 0009：封面主题、歌词排版与封面转场

日期：2026-10-11。范围：Slint 1.17.1 的歌曲歌词页；Windows 验收见[报告](../validation/lyrics-page.md)。

0.4.1 修订（2026-10-12）：用户实测返回搜索页时仍有残余歌词 / 按钮。取消整页仅按封面位移的平移，改为页头、歌曲信息、歌词三个区域的中心分别向左下小封面中心收拢，保持尺寸与换行。文字透明度用封面实际路程驱动，剩余进度不大于50%时为0；进入与返回共用smoothstep曲线，避免快速反向切换透明度规则。原封面480ms回弹、420ms主题混合与预定位保留，转场中内容操作禁用，大封面仍可快速反向。证据见 [0.4.1 验收](../validation/frontend-0.4.1.md)。

0.4.0 修订（2026-10-12）：下文按大字号预留高度与单纯淡入淡出的方案属于首次交付。本轮根据用户双语间距 / 转场反馈，改为各行实际字号与字重测量，普通行语言间距为当前行设置的70%；字号立即重排，颜色 / 透明度保留动画。浏览时保留隐藏布局并直接跟随当前位置，入场不从首行滚动；内容随封面的同一480ms进度位移，在固定内容区裁剪，避免透过半透明底栏。420ms背景 / 控件颜色混合保持。后续实现以[0.4.0验收](../validation/frontend-0.4.0.md)和[歌词指南](../LYRICS.md)为准。

## 背景与决定

用户要求以真实歌曲封面决定歌词页主题色，切页时从左下封面平滑展开 / 收回并略微回弹；普通 / 当前行和双语副语言的排版参数独立可调。原页使用全局主题色和固定 56px 行高，字号、双语或长句换行以后不能继续按索引乘常量定位。

沿用 Slint / AppController / libmpv 与已有有界资源服务，不引入新依赖。后台对已经解码、受尺寸限制的封面采样，最多 16384 个 RGBA 像素、512 个 RGB 桶，过滤透明与黑白边框，选择主要彩色簇；灰度图取真实中性色，全透明 / 无封面回退到应用主题色。只返回 RGB 数值，主线程不遍历图片。内嵌 / 同名 / 目录封面和联网资源共用算法，保留媒体 revision / 联网 lane 的过期回复保护。

默认启用封面取色和双语上下行；页内主题不改变全局界面、音频或视频策略。背景采用静态渐变、柔光色场和低频呼吸；可选原四种矢量背景以同一主题色着色，本地图保留透明度 / 后台模糊。替代候选为每首歌生成模糊封面大背景，但本次以轻量色场实现，不增加封面衍生纹理或逐帧图像操作。

## 配置与滚动

Settings v1 增加带 serde 默认值的 `lyrics` 对象，范围和默认见[歌词指南](../LYRICS.md)。校验有限整数、字号 / 间距 / 不透明度和标准字重；只在实际改动后增加设置 revision，复用既有延迟 / 原子持久化。歌词样式可在页内调整，也可在设置预览；文本焦点保护和面板关闭复用 UI / Winit 边界。

源歌词、LRC 时间戳 / offset 和播放状态不改。投影时拆开带空格的 ` / `，上方原文、下方译文；裸斜线 / 空分隔保留原样，关闭开关显示原始文本。TXT / 无时间轴歌词复用行组件，不能 seek。

每行以主语言两种字号的较大值测量实际换行高度，译文按 72% 字号测量，字重独立；空间按测量结果预留，活动行切换不让整个列表反复重排。当前行报告实际位置 / 高度，视口居中跟随，首尾用半视口留白；不按固定行高估算。很长的整组歌词可能超出视口，需要手动阅读，未增加逐字卡拉 OK / 自动语言识别。

## 转场与生命周期

歌词页作为可保留的覆盖页淡入 / 淡出，同一封面在真实左下 48px 位置与响应式大封面位置间移动 / 缩放。420ms 页面混合、480ms cubic-bezier 轻微回弹；快速反向操作改变同一动画的目标，500ms 的保留计时从最后操作重新开始。普通播放栏和大页面隐藏各自封面副本，只有覆盖封面在转场中绘制。

转场直接读取当前减少动态效果设置，支持同帧修改和切页；开启后立即到目标位置、撤销保留计时。离页即停背景 / 占位封面的持续动画；没有媒体、纹理或 UI 截图跨窗口复用，也没有 mpv render 或 GL prepare_gl 改动。主布局显式保留可伸展区域，避免覆盖页使播放选项压缩为零高度。
