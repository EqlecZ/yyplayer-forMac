# ADR 0008：移植 Android 云端 API v1 到 PC

日期：2026-10-09。用户授权在 Rust `dev-api` 实现，Android 工程只读取材。

用户要求独立联网搜索栏目，并共用 Android JSON 配置、搜索、音质、封面、歌词、下载和串流行为。PC 保留 Rust / Slint / 唯一 libmpv Engine，普通播放命令仍由 Engine worker 执行，不替换音频后端或修改既有输出默认值。

采用锁定 ureq 3.4.2 阻塞 HTTPS 客户端，仅在两个有界后台 worker 中运行，不引入全局异步 runtime。TLS 使用平台证书校验；手动处理最多6次重定向，拒绝 HTTP 与 POST 重定向，换主机或端口移除鉴权头。配置声明式解析与 Android v1 保持一致，包括嵌套 JSON、质量参数／变量覆盖、trackFields、精确媒体头、apiHosts、分页、歌词翻译和服务报告。

libmpv 普通 HTTP headers 不能替代按精确主机控制媒体访问头的客户端契约。串流因此使用只监听 `127.0.0.1` 的短期随机路径代理，最多两个连接；它转发 Range/长度/类型，内部访问 HTTPS，凭据和上游地址不进入 mpv。完整顺序响应保存到用户选择的缓存目录，下次相同稳定曲目与请求音质可以复用。代理失效或关闭联网后不会用旧地址自动续播。歌曲身份使用 provider/source/id，歌词与资源回复另绑定请求及媒体资源版本。

PC 下载用同目录 `.partial`，检查实际长度、512MiB上限与文件头，按歌名／歌手与真实扩展名发布，重名递增。Windows 无覆盖原子重命名；Linux 用同目录无覆盖 hard-link 发布。歌词／图片尽力保存同名 LRC/JPG，已完整下载的音频不会因辅助资源失败而失去。下载后加入现有库并可立即播放；元数据关联保存到本地设置（最多256条），临时地址和API凭据不保存。

默认 API 路径在 exe 旁 `config/cloud_api`；安装目录只读时选择其他目录。歌曲、歌词、图片、串流目录可分别设置。自动缓存仅清理应用专属子目录中的完整 SHA-256 文件名，保留手动选中的歌词；不删除用户库文件。

验收用自有低幅 WAV／FLAC、原创歌词和几何封面及独立配置。显式 `online-qa`/单测才可为 localhost 加载生成的测试 CA，普通 Release 不包含该入口；不安装系统根证书。数据和UI验收见 [记录](../validation/online-api.md)。第三方供给、真实用户账号、Linux新功能与特殊文件系统仍需各自验收。
